## 跨对话记忆机制

### 目标
- 防止长时间对话后遗忘早期关键内容。
- 每个对话把自己的关键内容保存到独立的 `.md` 文件中，恢复上下文时直接读取对应文件。
- 对话之间相互隔离：一个对话只能查看/覆盖自己的记忆文件，除非用户明确授权查看其他对话的文件。

### 目录结构
```
.trae/memory/
  对话ID_话题名.md      # 每个对话一个文件
```

### 规则
1. 每次开始新对话时，先检查 `.trae/memory/` 是否存在当前对话的记忆文件；存在则读取以恢复上下文。
2. 在对话过程中周期性落盘（大约每完成一个完整主题、或对话较长时），把以下内容追加/更新到本对话的记忆文件：
   - 对话目标与背景
   - 已得出结论/决策
   - 待办事项
   - 修改过的文件路径与关键代码位置
   - 尚未解决的问题
3. 触发时机（不依赖"超限倒计时"，主动按节奏写）：
   - 对话时间/轮次较长时；
   - 每完成一个主题单元后；
   - 用户明确说"记住"时。
4. 对话过长时的主动恢复：
   - 当对话轮次明显变长、或发现自己对较早内容把握不足时，主动读取当前对话的记忆文件以恢复上下文，再把新结论回写（写前先读，避免覆盖）。
   - 读取只限于当前对话自己的记忆文件；其他对话仍遵循文件隔离原则。
5. 文件隔离：
   - 当前对话只读写自己的记忆文件。
   - 不得读取或引用其他对话的 `.md` 文件，除非用户明确提出"查看/对比其他对话"。
6. 用户可以在任意时刻命令：`把当前对话存档` 或 `让我查看对话X的记忆`，据此立即执行。
